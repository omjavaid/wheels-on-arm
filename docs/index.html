Clicking a package name opens its source repository (from PyPI's metadata) — that's where to open an issue or PR about a missing wheel. The small "pypi" link next to it opens the PyPI files page instead, to check wheels directly. ★ marks packages on strategic.json, a hand-curated list of AI/ML/data-science tooling considered important regardless of raw download count — these are always scanned and always shown, even outside the selected "Top N" view. Priority score combines download volume with feasibility signals (already built for Arm64 elsewhere, stable ABI, release maturity/recency) plus a flat bonus for strategic packages — see compute_priority() in scan.py for the exact formula, and treat the score as a starting point for investigation, not a guarantee.
